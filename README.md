# HomewAtomSpace
This repository created for Python-AtomSpace-Course homework

## In this repository:
To keep the workspace clean and organized, each homework assignment is isolated in its own Git branch.
Getting Started

## If you want to clone this repository and run the code locally, follow these standard steps:

1. Clone the repository:
Bash
```
git clone git@github.com:MariaLysiukq/HomewAtomSpace.git
cd git@github.com:MariaLysiukq/HomewAtomSpace.git
```

2. Set up a virtual environment (Recommended):
It is best practice to use an isolated environment for running Python scripts.
Bash
```
python3 -m venv .venv
source .venv/bin/activate
```
(Note for Windows users: run .venv\Scripts\activate instead)

# Tools & Environment

    Language: Python 3.10+
    Version Control: Git
    Environment: Virtual environment (.venv)

# About branches

1. Second_homework.py focuses on processing user input, manipulating strings, utilizing different data structures (Lists and Sets), and building robust programs with error handling.

2. task_third_homework.py - a basic console calculator that allows users to perform basic arithmetic operations.

3. Fourth_homework.py - transitions from flat scripts to a modular programming approach. It features a complete user registration flow that validates, processes, and securely obfuscates user input using dedicated Python functions.

4. reservation_system.py - introduces Object-Oriented Programming concepts by modeling a cinema ticket booking system. It demonstrates how to structure code using classes, manage internal state, and apply inheritance.

5. bitter - terminal-based Social Network. This project is a multi-module console application that simulates a mini social network called "Bitter" (a conceptual clone of Twitter). It transitions from single-file scripts to a structured, modular architecture.

6. rest_api.py - demonstrates how to interact with external web services using Python's `requests` library. It implements a fully functional console client for a dummy REST API (`jsonplaceholder`), allowing users to perform standard CRUD (Create, Read, Update, Delete) operations.
